VELO 是什么

VELO 是一款为 iPhone 设计的离线 GPS 测速应用。打开它，你就能看到当前速度，以及本次行程的时长、距离、平均速度和最高速度。

测速功能不依赖 Wi-Fi 或移动数据。位置和行程只在这台手机上处理，不会上传到我们的服务器。

它能做什么

  • 用 iPhone 定位测量实时速度，支持 km/h 与 mph
  • 显示本次行程的时长、距离、平均速度和最高速度
  • 可设置速度提醒；超过你设定的数值时，仪表盘会高亮提示
  • 开始、暂停、继续和重置当前行程
  • 演示模式用于体验界面，显示的是明确标注的模拟数据

使用说明

请允许“使用 App 期间”访问位置，并开启精确位置。在开阔处使用效果更好；室内、隧道或高楼遮挡可能没有有效读数。尚无有效速度时，仪表会显示 0 和当前定位状态，这个 0 不代表你已经静止。

测速时屏幕会保持常亮。切到后台或锁屏后自动暂停，返回后可以继续。暂停和信号中断期间不会累计距离。

距离由有效速度读数估算，平均速度只统计有效读数之间的时间。速度提醒由你自行设定，不代表道路限速。实际出行前，请在设置中关闭演示模式。

数据与隐私

VELO 不向服务器上传位置或行程数据，也不加入广告跟踪。显示单位和速度提醒保存在本机。本次行程只留在内存中，退出应用后不会保留。
