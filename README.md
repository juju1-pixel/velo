# VELO · 时速

原生 iPhone 应用，工程位于 **[ios/Velo.xcodeproj](ios/Velo.xcodeproj)**。

- **技术栈**：Swift 6、SwiftUI、Core Location、Swift Charts。
- **最低版本**：iOS 17。
- **核心功能**：离线 GPS 测速、单位切换、开始/暂停、行程统计和速度提醒。
- **运行与实现说明**：[ios/README.md](ios/README.md)。

项目仅保留原生 iOS 工程，直接使用 Xcode 构建。
